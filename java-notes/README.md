# Java Learning Notes

This repository contains my Java learning notes and examples.

## What is Java
Java is a high-level, object-oriented programming language developed by Sun Microsystems in 1995.

## History of Java
Java was created by James Gosling and his team at Sun Microsystems.
The first public release was Java 1.0 in 1996.

## Why Java
- Platform Independent (Write Once Run Anywhere)
- Object Oriented
- Secure
- Robust
- Large Community
